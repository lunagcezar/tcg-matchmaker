# Introduction

This specification implements tournament pages with D3.js bracket visualization.

## Pages

- `/tournaments` — ListPage: browse tournaments
- `/tournaments/new` — CreatePage: create tournament
- `/tournaments/:id` — DetailPage: info, register, bracket view
- `/tournaments/:id/manage` — ManagePage: check-in, publish, start, advance
