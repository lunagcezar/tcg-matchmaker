# PWA Setup

## 1. Purpose & Scope

Enable Progressive Web App (PWA) support for the frontend (NFR-45). The Quasar config already has PWA settings (`workboxMode: 'GenerateSW'`) but the required `src-pwa/` directory is missing. This spec creates the service worker registration, manifest, and uncomments the source file mappings.

## 2. Definitions

| Term           | Definition                                                                              |
| -------------- | --------------------------------------------------------------------------------------- |
| Service worker | Script that runs in the background, enabling offline caching and push notifications     |
| Manifest       | JSON file that configures how the PWA appears when installed (name, icons, theme color) |
| GenerateSW     | Workbox mode that auto-generates the service worker file at build time                  |

## 3. Requirements, Constraints & Guidelines

- **REQ-001**: Create `src-pwa/register-sw.ts` — registers the service worker generated by Workbox
- **REQ-002**: Create `src-pwa/manifest.json` — web app manifest with name, short_name, theme_color, background_color, display, icons
- **REQ-003**: Update `quasar.config.ts` to uncomment `sourceFiles.pwaRegisterServiceWorker` and `sourceFiles.pwaManifestFile`
- **REQ-004**: Icons are placeholder-sized PNGs — documented as a TODO for when design assets are ready
- **REQ-005**: Build command should remain SPA-mode (`quasar build`), with PWA features enabled via the config
- **CON-001**: Uses Quasar CLI PWA mode with `GenerateSW` (no custom service worker needed for initial setup)
- **CON-002**: No changes needed to deployment — Cloudflare Pages already handles the SPA output

## 4. Acceptance Criteria

- **AC-001**: Given the build runs, When `quasar build` is executed, Then the output includes a service worker file and manifest.json
- **AC-002**: Given a browser that supports PWA, When visiting the deployed site, Then the browser shows the install prompt
- **AC-003**: Given the manifest is installed, When viewing the app info, Then the app name and theme color match the manifest

## 5. Dependencies

- Quasar PWA mode (built-in, no additional packages needed)
- Workbox (bundled with Quasar)
- Icons: placeholder task for future design work
